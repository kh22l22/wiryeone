위례 ONE 시연용 예시 사진 출처

이 폴더의 사진 21장은 모두 AI로 생성한 합성 사진이다(manifest의 synthetic: true).
실제 장면을 찍은 사진이 아니며, 외부 사진(Wikimedia 등)이나 저작자 표시가 필요한 소재는 쓰지 않았다.
사진 속 사람, 이름, 전화번호, 주소, 차량 번호, 학교·회사·상호, 카드는 모두 가짜다.
탐지 성능 평가의 정답 자료가 아니라 시연용 자료다.

구성
  앱의 문제 유형(사진이 필요한 상황)마다 3장씩 7개 상황, 21장.
  도로·보도 파손(R1), 가로등·시설물(R2), 쓰레기·환경(R3), 공원·녹지(R5),
  킥보드·자전거 방치(R6), 동물·야생동물(R8), 주운 물건(지갑·카드 등)(L1).
  불법주정차는 안전신문고 앱 촬영만 받으므로 만들지 않았다.

제작 방식
  배경: OpenAI Codex CLI 0.166.0의 내장 이미지 생성 도구로 생성했다. 사용자의 ChatGPT 로그인으로 실행했고 API 키는 쓰지 않았다.
        글자·로고 없이, 라벨·종이·번호판·카드·휴대폰 화면은 빈 흰 면으로만 그리게 했다.
  글자 합성: Python(Pillow, NumPy)으로 가짜 글자를 그려 빈 흰 면에 원근 변환해 곱하기 합성했다(휴대폰 화면은 치환).
  자연스럽게 다듬기(2026-11-15): 잉크색·번짐·흐림을 장면에 맞춰 합성한 뒤, 15장은 Codex 이미지 생성으로 같은 장면·같은 글자를 다시 그려 인쇄물처럼 보이게 했다.
            다시 그린 뒤 글자 인식(OCR)과 눈으로 글자가 바뀌지 않았는지 확인했고, 바뀐 6장(kickboard-sidewalk-1, sidewalk-sink-3, bus-shelter-broken-2, park-bench-2, dumping-bags-1, bike-abandoned-2)은 합성본을 그대로 썼다.
            일부 사진은 얼굴·글자가 작지 않도록 원본 일부를 잘라 확대했다.
  글꼴: Windows 맑은 고딕(Malgun Gothic). 이미지 안의 글자로만 쓰며 글꼴 파일은 배포하지 않는다.
  QR·바코드: qrcode 패키지(내용 https://example.com), python-barcode 패키지(Code128, 무작위 가짜 번호).
  저장: 긴 변 1600px, JPEG 품질 88, EXIF 없음.

들어 있는 가짜 정보의 종류
  행인 얼굴: AI가 만든 성인 가상 인물. 실존 인물이 아니며 미성년자는 넣지 않았다.
  차량 번호판: 38가 1729, 214나 6385처럼 실제 형식을 따른 무작위 가짜 번호. 실제 번호판처럼 세로로 긴 글자로 그렸다.
  전화번호: 010-1xxx-xxxx 형식의 무작위 가짜 번호(전단, 안내문, 차량 연락처 표지, 택배 송장, 휴대폰 화면, 카드). 실제 가입자와 겹치지 않는다고 보장할 수는 없으므로 전화하지 마세요.
  이름·주소: 김민준, 이서연처럼 흔한 이름과, 위례 실제 도로명에 없는 단지·동·호수를 붙인 가짜 주소(예: 위례광장로 318, 푸른숲마을 1204동 1503호).
  이메일: 실제 메일 서비스 형식의 가짜 주소(예: doyun.lee91@gmail.com). 보내지 마세요.
  카드류: 신분 확인 카드, 체크카드, 교통카드, 학생증, 사원증. 모두 실제 신분증·카드 디자인이나 기관 로고를 흉내 내지 않은
          단순한 도안이다(빨간 "견본" 도장은 넣지 않았고, 신분 확인 카드 머리글에만 "견본"이 있다). 학생증은 사물로만 넣었고 사진 자리는 사람 모양 아이콘이다.
  QR코드: 내용은 https://example.com.
